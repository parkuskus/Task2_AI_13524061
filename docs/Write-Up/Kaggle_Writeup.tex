\subsection{Permasalahan}

Tugas: memprediksi \texttt{loan\_status} (0 = ditolak, 1 = disetujui) untuk setiap pemohon berdasarkan data demografis, finansial, dan riwayat kredit. Metrik evaluasi: \textbf{Macro F1-score}.

\subsection{Dataset}

\begin{itemize}
    \item \textbf{Train set}: 36.000 baris (28.000 label 0, 8.000 label 1) --- tidak seimbang
    \item \textbf{Test set}: 9.000 baris tanpa label
    \item \textbf{Fitur}: 12 kolom (numerik + kategorik), tanpa missing values
    \item \textbf{Target}: \texttt{loan\_status} (hanya di train.csv)
\end{itemize}
